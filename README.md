**CommitmentIssues** — the one word for my Wi-Fi.

It is always there, right up until the moment you actually need it — then it drops, reconnects, drops again, and pretends nothing happened. It never really leaves; it just refuses to commit. Rename the network to this and every guest will know exactly what they are in for.

`main.py` writes exactly that one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, with a runtime self-check that it is a single word of 1–20 characters.
